Preferences Window

The Preferences window provides options that apply to Doom Builder, regardless of the game configuration or map you choose to edit. You can access this window from the Tools menu, or with the default key F5. The options are categorized in different tabs;

Interface

This tab contains some interface related options.

Default view:

This sets the default view mode that you wish to use when opening or creating a new map.

Preview image size:

The size of all preview images in the editor and in the Image Browser. Smaller preview images consume less system memory.

Autoscroll speed:

During some actions, such as drawing and dragging, Doom Builder can automatically scroll the working area when you move your mouse towards the edges. Use this setting to set the scrolling speed to use. Drag the slider completely to the left to turn off automatic scrolling.

Vertex scale factor (GZDB only):

Controls the size of vertex handles in Visual modes. The Classic modes setting is on the 2D View tab.

Max. recent files (GZDB only):

Controls how many recent files are shown in the File menu.

Script Editor always on top of main window:

Check the box if you want the script editor to float above the Main Window even when the script editor does not have the focus.

Sync camera position between 2D and 3D modes (GZDB only):

When enabled, GZDoom Builder will center 2D-mode on Visual Camera position when you leave Visual mode, and will place Visual Camera at cursor position when you toggle from 2D mode to Visual Mode (unless you have Visual Mode camera thing in your map).

Visual Modes:

This area contains several settings for the Visual Mode. To improve performance, you may want to decrease the View distance setting.

Advanced

Settings that could only be changed by editing the program configuration file before.

Recent textures kept:

How many textures and flats the recent-texture palette remembers. 0 turns the history off.

Show modifier key hints while a modifier is held:

When a modifier key such as Ctrl, Shift or Alt is held for a moment, the Help side panel lists what the held keys do in the current mode.

Use the desktop's file chooser (zenity) (Linux only):

Open files and folders with the desktop's file chooser through zenity when it is installed. Turn it off to use Mono's own dialogs.

Horizontal and vertical look speed:

Multipliers of the Mouse speed setting for mouse look in Visual Mode, one per direction (default 40).

Frame pacing and minimum frame time (Linux only):

Frame pacing paces Visual Mode frames by the display's refresh and waits at least the minimum frame time between them; raise it to lower the frame rate and the load. Turning frame pacing on or off applies after a restart; the minimum frame time applies at once.

Controls

This is where you configure your keyboard and mouse shortcut keys. On the left is a list of all Actions in Doom Builder with the current mouse or key combination shown next to them. Select an action to view a summary of this action on the right. Press any key combination to set to this action, or select a special mouse combination from the drop down box. Below that, you can see which other actions share the same key combination so that you can verify any conflicts it may have. Note that actions used in different editing modes can safely share the same key combination.

Appearance

On this tab you can change some settings related to visual aesthetics. On the top and the left of this tab you can change colors that are used in the Working Area and set the font and other options regarding the Script Editor.

Passable lines transparency:

This controls how much translucent the passable lines are. 0% is completely opaque, which is the same as impassable lines. Passable or impassable can be set with a linedef setting, but is automatically set by the editor for singlesided lines and removed for doublesided lines.

Textures and Flats brightness:

With this setting you can increase the brightness of the textures and flats. This is useful when viewing the texture against a white background, or if you are using a dark monitor.

Maximum dynamic lights to render (GZDB only):

Lets you choose how many dynamic lights to render in Visual mode. Decrease this to improve performance when Dynamic Lights Rendering is on. Possible values are [1..32].

Dynamic light size (GZDB only):

This option mimics GZDoom's "light size" option.

Dynamic light intensity (GZDB only):

This option mimics GZDoom's "light intensity" option.

Square things:

Things in Doom use a square shape for collision detection and you may want to turn this option on to get a better view on the bounding boxes of things in the classic Editing Modes (2D).

High quality display rendering:

This improves the display with the use of Pixel Shader Model 2.0. Also adds anti-aliasing to the classic Editing Modes (2D). Performance may be improved by turning off this setting (this also gives a more oldschool Doom Builder 1.68 look to the working area). When Pixel Shader Model 2.0 support is not available, Doom Builder automatically turns off this setting and disables this option.

Bilinear filtering in classic modes:

This enables bilinear texture filtering for all classic Editing Modes (2D). Bilinear texture filtering removes the large square blocks when zooming in, but can also make it look blurry.

Bilinear filtering in visual modes:

This enables bilinear texture filtering for all visual Editing Modes (3D). Bilinear texture filtering removes the large square blocks when zooming in, but can also make it look blurry.

Load GZDoom light definitions (GZDB only):

When enabled, GZDoom's built-in GLDEFS dynamic light definitions will be loaded.
Warning: if a map is loaded, you'll need to reload resources after changing this option to apply the changes.

Scale models in visual modes (GZDB only):

When enabled, height of models will be scaled down by 15% in Visual mode to mimick GZDoom's way of rendering them.

Black background in image browser:

Turn this on to create a black background in the Image Browser.

Always show selection in visual modes (GZDB only):

When enabled, selected surfaces will be highlighted in Visual mode even if "Show highlight" mode is disabled (Doom Builder 2 behaviour).

Mark 3D floors in classic modes (GZDB only):

When enabled, linedefs of sectors with 3D floors will be marked using "3D Floors" color.

Sector labels and Measurements colors:

The text color of sector labels (tags and effects shown in the classic modes) and of length and angle labels shown while drawing or dragging. They start as the Event lines and Highlight colors they used before they had their own.

2D View

Settings for how the classic Editing Modes (2D) draw the map. Changes apply when you press OK.

Linedef thickness:

The width of linedefs in pixels, from 1 (default) to 5. Their normal indicators and the 3D floor markings follow it, and vertices grow so they are never narrower than the lines under them. The grid and other overlays stay 1 pixel wide.

Vertex scale (2D):

Controls the size of vertex handles in the classic modes. Vertices grow as you zoom in, up to a size that grows with this setting.

Text Labels:

The font, size and bold style of the text labels drawn on the map. Sector labels, selection numbers, measurements (length and angle labels) and event line labels can each have their own size; (same) uses the size set above. Background sets how opaque the box behind sector labels, selection numbers and measurements is; 0% draws no box.

Compilers

Lists every script compiler and nodebuilder the editor found in its compiler configurations, with the program each one runs, whether that program exists, and which script or nodebuilder configurations use it. Select a compiler and fill in Override (or use Browse...) to run another program instead, for example a different build of a script compiler; Reset goes back to the program the compiler configuration names. An override must be the absolute path of an existing file when you set it (one whose file later disappears shows as missing), and it is used from the next compile on.

Pasting

The default options for pasting geometry. Clipboard history entries sets how many copies the clipboard history panel keeps; 0 turns it off.

Appearance

Default sector settings (GZDB only):

Allows you to modify setting used when drawing a new sector. These settings can be overriden using Draw Settings Panel.

Auto-align textures on newly created linedefs (GZDB only):

When enabled, auto texture alignment will be applied to sidedefs created after drawing deometry.

Don't move selection if any part of it is outside of map boundary (GZDB only):

When enabled, geometry outisde of map boundaries can not be dragged. When disabled, geometry will be moved inside of map boundary, most likely destroying sector shapes in the process (Doom Builder 2 behaviour).

Synchronise selection between Visual and Classic modes (GZDB only)

Give each event line group its own color:

When enabled, event lines drawn for different actions get different colors; when disabled, they all use the first color.
