Map Statistics

The Map Statistics window collects information about the current map in one place. Open it with View -> Map Statistics... or its toolbar button (shown with the View toolbar buttons). Edit -> View Thing Types... opens it on the Things tab and Edit -> View Used Tags... on the Tags tab. Otherwise it opens on the tab you had open last.

The numbers are computed when the window opens. Edits made from inside the window (right-click edits on the Things and Tags tabs) update the other tabs when you switch to them.

Overview

Map name, format and game configuration; vertex, linedef, sidedef, sector and thing counts next to the format's limits (shown in red when a limit is exceeded); map bounds and size; linedefs with an action, tagged linedefs and sectors, sectors with an effect and secret sectors; things of unknown type; player and deathmatch starts; script counts when the map has ACS; and how many wall textures and flats are used and missing. Copy puts the whole list on the clipboard.

Tally

What the game would count for this map, one column per skill level: kills, items, secret things, secret sectors and the secrets total, plus the total spawn health of the counted monsters and the health, armor and ammo the map's pickups give. Pick Single player, Cooperative or Deathmatch in the Mode list; Hexen games also have a Class list, since things can be limited to one player class.

The counts follow the things' skill, mode and class flags, and friendly, nocount and countsecret things are handled the way the game handles them. Whether a thing type counts as a kill or an item, and how much it gives, comes from the map's DEHACKED patch, the actor definitions (DECORATE and ZScript, including the engine's own when it is loaded as a resource), the game configuration's DEHACKED data, or the original Doom values, in that order. Thing types none of these explain are listed in an Unresolved things row instead of being guessed.

Health, armor and ammo are raw sums of pickup amounts: maximums, monster drops and skill ammo factors are not applied, and weapons count at their single player amount.

Click a cell in the Kills, Items, Secret things or Unresolved things row to select those things in Things mode; a Secret sectors cell selects the sectors in Sectors mode. Copy puts the table on the clipboard as tab-separated text.

Things

Every thing type the game configuration and resources define, with its category and how many of it the map has. The Category list shows one category, and Hide Unused Things hides the types the map doesn't use. Click a row to select those things, right-click to edit them.

Textures

Every wall texture and flat the map uses, how often, and whether it is missing from the loaded resources. Click a texture to select the linedefs using it, or a flat to select the sectors using it.

Tags

The tags used by sectors, linedefs and things, with their labels. See Enhanced Tag support for label editing. Label changes are kept when you close the window with OK and discarded with Cancel.
