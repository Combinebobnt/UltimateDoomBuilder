Macros

Menu path: Tools -> Macros
Toolbar: the Macros strip (a record button and a run button with a list of macros)
Actions: "Record Macro", "Run Last Macro", "Manage Macros" and "Run Macro Slot 1" to "Run Macro Slot 10" (Macros category). None has a default key; you can bind them in Preferences -> Controls.

A macro is a recorded list of editor actions that you can play back later with one click or key. Each run is a single undo step, and a run that fails part way leaves the map as it was.

Recording a macro

  1. Open a map and switch to the mode the macro should work in.
  2. Choose Tools -> Macros -> Record Macro, or click the record button on the Macros toolbar.
  3. Use the actions you want to repeat, with their keys, the menus, the toolbar or the command palette. The status bar counts the recorded steps and names the last one.
  4. Choose Stop Recording (the same menu item and button). A window shows the recorded steps: give the macro a name, optionally pick a key slot, and click Save, or Discard to drop it.

The same action used several times in a row is stored as one step with a count (for example Raise floor by 8 x3). Saved macros are kept in the program settings, so they are available in every map and survive a restart.

What is recorded

A macro records which actions you used, not where you clicked. It does not store mouse positions, element numbers or values typed into dialogs. These are not recorded, and the status bar says so when you use one while recording:

  • actions started with a mouse button (selecting, dragging, drawing). Mouse wheel actions are recorded;
  • actions that start or end a drawing, pasting or selection editing mode, and anything done inside such a mode;
  • actions that do nothing in the current mode;
  • view navigation (scrolling, zooming, centering, moving the 3D camera), opening, saving and testing maps, Undo and Redo, Preferences and other settings windows, screenshots, exports and the macro actions themselves.

Changes made by dragging with the mouse or by editing values in a dialog are not part of the macro. When such a change happens while recording, the status bar shows Not recorded: <what changed>. An action that opens an edit dialog (for example Edit Sector) can still be recorded: when the macro runs, the dialog opens for you to fill in.

Running a macro

  • Tools -> Macros lists every saved macro; click one to run it.
  • Run Last Macro (menu, or a click on the toolbar run button) runs the macro you ran or saved most recently in this session. The arrow beside the toolbar button lists all macros.
  • A macro with a key slot runs from the key bound to that slot's "Run Macro Slot" action.

A macro works on what is selected or highlighted when it runs. Actions that act on the highlighted element or on the mouse position use the current mouse position, so run such a macro from its slot key with the mouse over the map rather than from a menu. Modifier keys held with the slot key (for example Ctrl or Shift) stay held while the macro runs, so actions that behave differently with a modifier held will do so.

Undo: each run is one undo step named Macro: <name>, and it never merges with the edit you made before it. A macro that only changes the selection leaves the undo history and the redo history as they were.

When a run stops

A run is all or nothing. If a step fails, every change the run made so far is undone and the status bar shows Macro 'name' stopped at step N (action): reason; changes rolled back. A run stops when:

  • you cancel an edit dialog that a step opened;
  • a step's action does nothing in the current mode;
  • a step leaves a drawing or editing mode open;
  • a step fails with an error (it is also listed in the Errors and Warnings window).

A step that refuses to run because there is nothing for it to do (for example snapping geometry that is already on the grid) does not stop the run: the following steps still run.

Modes

A macro remembers the editing mode it was recorded in and only runs in that mode; in other modes its menu entry is disabled and its slot key shows why it can't run. Check Run in any mode in the macro's settings to allow it everywhere, for example for a macro whose first step switches to the mode it needs.

Managing macros

Tools -> Macros -> Manage Macros... lists every macro with its slot key, steps and mode. From there you can run, edit, duplicate or delete a macro. Editing changes the name, the key slot (giving a macro a slot another macro has moves the slot to it), Run in any mode, and the steps: remove steps, move them up or down, or change how many times each one repeats.

A macro that uses an action from a plugin that is not loaded is kept but marked unavailable, and it does not run until the plugin is back.

Toolbar

The Macros toolbar strip can be hidden with a right-click on the toolbar (the Macros item) or in Preferences, beside the other toolbar options. Recording and running are disabled while no map is open, and running is disabled while recording.
