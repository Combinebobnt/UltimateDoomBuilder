Reject Explorer Mode

This mode lets you view the map's reject data. Available in Doom and Hexen format.
Menu path: Mode -> Reject Explorer
Action category: Modes.
Default key: None.

Move the mouse over a sector to highlight it. Every other sector is colored by the line of sight that the REJECT lump allows between it and the highlighted sector. The highlighted sector's info is shown in the info panel. Press Escape to return to the previous mode.

Colors (default):

Color Description
Gray there is no line of sight between the highlighted sector and this sector
Light green currently highlighted sector
Dark green there is a bidirectional line of sight between the highlighted sector and this sector
Yellow there is a unidirectional line of sight from the highlighted sector to this sector
Purple there is a unidirectional line of sight from this sector to the highlighted sector

Colors can be customized with the Configure colors button in the toolbar. The Color Configuration window sets the default, highlight, bidirectional, unidirectional from and unidirectional to colors. Reset colors restores the colors listed above.

REJECT lump
The mode shows the REJECT lump stored with the map. It does not change while you edit sectors. The mode does not start when the map has no REJECT lump, when the lump is empty, or when it is smaller than the current number of sectors needs (for example after sectors were added since the lump was built). A lump that is larger than needed is used, with a warning.
