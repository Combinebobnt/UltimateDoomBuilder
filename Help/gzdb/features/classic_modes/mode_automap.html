Automap Mode

This mode is based on the Automap Mode plugin by Boris Iwanski (https://github.com/biwa/automapmode).

This mode displays the map as it is shown in the game's automap, and lets you edit the automap related flags of lines and sectors. Available in all map formats.
Menu path: Mode -> Automap Mode
Action category: Modes.
Default key: None.

What is shown
Like the game's automap, only lines that matter on the automap are drawn by default: one-sided lines, lines with the "Shown as 1-sided on automap" flag, and two-sided lines between sectors of different floor or ceiling height. Lines with the "Not shown on automap" flag are left out.

Line colors with the Doom color preset:

Color Line
Red one-sided line, or a line with the "Shown as 1-sided on automap" flag
Brown two-sided line between sectors with different floor heights
Yellow two-sided line between sectors with the same floor height but different ceiling heights
Dark gray two-sided line with no height change (only drawn when hidden lines are shown)
Light gray line with the "Not shown on automap" flag (only drawn when hidden lines are shown)
Magenta line of a secret sector, when Show secrets is enabled
Lock color locked line, when Show locks is enabled; the color comes from the lock's definition in the game data

When several rules apply to a line, a lock color wins over the secret color, which wins over the flag and height colors.

Mouse and keys
The mode has no actions of its own besides the one that switches to it. It uses the standard Select and Edit actions:

  • Left click (Select) on a line toggles its "Shown as 1-sided on automap" flag.
  • Right click (Edit) on a line toggles its "Not shown on automap" flag.
  • Hold Ctrl to toggle the display of the lines that are not drawn, either because there is no height change (dark gray) or because the "Not shown on automap" flag is set (light gray). Ctrl inverts the Show hidden lines toolbar setting while it is held.
  • [UDMF] Hold Shift to highlight and edit sectors instead of lines. Clicking a sector toggles its "Not shown on textured automap" flag. Sector textures are shown while Shift is held.

Each toggle can be undone. The highlighted line or sector is shown in the info panel.

Toolbar
The mode adds these controls to the toolbar. Their settings are remembered between sessions.

  • Show hidden lines: also draw the lines the automap would not draw (see the table above).
  • Show secrets: draw the lines of secret sectors in magenta. A sector is secret when its effect is 9 or has the secret generalized flag in Doom format maps, or when it has the secret generalized flag in Hexen and UDMF format maps.
  • Show locks: draw locked lines in their lock color. A line is locked when its action takes a lock number and that argument is set, or in UDMF when its lock number field is set. Not shown for Doom format maps.
  • Show textures: draw sector textures under the lines. Sectors with the "Not shown on textured automap" flag are skipped. When disabled, the background is filled with the color preset's background color.
  • Color preset: Doom, Hexen or Strife automap colors.
